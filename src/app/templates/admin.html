API-Zugriff für externe Programme

Erstellen Sie API-Keys, damit CRM-Systeme, PVS oder andere Programme sich mit diesem Tool verbinden können.

Verwendung

Externe Programme authentifizieren sich per HTTP-Header anstelle eines Login-Tokens:

curl -H "X-API-Key: ebm_live_..." https://your-domain/api/interop/status

Jeder Key ist auf bestimmte Bereiche (Scopes) beschränkt: interop (GDT/FHIR), analysis (Instant-Analyse), patients (Patientenverwaltung), cases (Fallakten lesen).

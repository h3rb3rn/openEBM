    Database Schema¶

    PostgreSQL 16. All tables use String(36) UUIDs as primary keys (generated by Python uuid.uuid4()), not PostgreSQL native UUID type. SQLAlchemy 2 async session (asyncpg driver).

    Tables¶

    tenants¶

    Column Type Notes
    id VARCHAR(36) PK UUID
    name VARCHAR(255) Display name
    slug VARCHAR(100) UNIQUE URL-safe identifier
    is_active BOOLEAN Soft-disable
    settings JSON Tenant-specific config blob
    created_at DATETIME
    updated_at DATETIME Auto-updated

    users¶

    Column Type Notes
    id VARCHAR(36) PK
    tenant_id VARCHAR(36) FK→tenants CASCADE delete
    email VARCHAR(320) UNIQUE per tenant
    hashed_password VARCHAR(255) bcrypt
    full_name VARCHAR(255)
    role ENUM(UserRole) admin, arzt, mfa, readonly
    is_active BOOLEAN
    created_at DATETIME
    last_login DATETIME NULL

    Unique constraint: (tenant_id, email).

    patients¶

    Column Type Notes
    id VARCHAR(36) PK
    tenant_id VARCHAR(36) FK→tenants CASCADE delete
    patient_number VARCHAR(50) UNIQUE per tenant
    first_name VARCHAR(100)
    last_name VARCHAR(100)
    date_of_birth DATE
    gender ENUM(Gender) m, w, d
    insurance_type ENUM(InsuranceType) GKV, PKV, SELBSTZAHLER, BG
    insurance_id VARCHAR(50) NULL Versichertennummer
    insurance_company VARCHAR(255) NULL
    is_active BOOLEAN Soft-delete
    created_at DATETIME
    updated_at DATETIME

    Indexes: (tenant_id), (tenant_id, patient_number) UNIQUE.

    case_files¶

    Column Type Notes
    id VARCHAR(36) PK
    tenant_id VARCHAR(36) FK→tenants CASCADE delete
    patient_id VARCHAR(36) FK→patients CASCADE delete
    created_by_id VARCHAR(36) FK→users No cascade
    treatment_date DATE
    report_text TEXT Full physician report
    report_version INTEGER Default 1
    status ENUM(CaseStatus) offen, in_bearbeitung, abgeschlossen, archiviert
    quartal VARCHAR(6) e.g. 2024Q1
    notes TEXT NULL
    created_at DATETIME
    updated_at DATETIME

    Indexes: (tenant_id, patient_id), (tenant_id, quartal).

    gop_suggestions¶

    Column Type Notes
    id VARCHAR(36) PK
    case_file_id VARCHAR(36) FK→case_files CASCADE delete
    gop_code VARCHAR(10) EBM code
    gop_description TEXT NULL Human-readable description
    start_char INTEGER NULL Offset in report_text
    end_char INTEGER NULL Offset in report_text
    source_text TEXT NULL Extracted evidence snippet
    confidence FLOAT 0.0–1.0, LLM confidence score
    color_hex VARCHAR(7) Background colour for highlight (deterministic hash of code)
    status ENUM(GOPStatus) vorgeschlagen, akzeptiert, abgelehnt
    mcp_validated BOOLEAN True when MCP passed
    mcp_exclusion_flags JSON NULL Raw MCP rejection details
    llm_reasoning TEXT NULL Chain-of-thought reasoning if enabled
    created_at DATETIME
    updated_at DATETIME

    Indexes: (case_file_id), (gop_code, case_file_id).

    audit_logs¶

    Immutable append-only table. Satisfies § 203 StGB / GDPR accountability requirements. Rows are never updated or deleted.

    Column Type Notes
    id VARCHAR(36) PK
    tenant_id VARCHAR(36) FK→tenants CASCADE delete
    user_id VARCHAR(36) FK→users NULL SET NULL on user delete
    case_file_id VARCHAR(36) FK→case_files NULL
    gop_suggestion_id VARCHAR(36) FK→gop_suggestions NULL
    action ENUM(AuditAction) See below
    gop_code VARCHAR(10) NULL
    reason TEXT NULL Optional human comment
    log_metadata JSON NULL Arbitrary context blob
    ip_address VARCHAR(45) NULL IPv4 or IPv6
    created_at DATETIME

    AuditAction values: gop_akzeptiert, gop_abgelehnt, gop_vorgeschlagen, fallakte_erstellt, fallakte_abgeschlossen, analyse_gestartet.

    Indexes: (tenant_id, created_at), (case_file_id).

    Hard-delete protection

    Users with audit-log entries cannot be hard-deleted (FK constraint). The admin API returns HTTP 409 and directs the caller to deactivate the user instead.

    api_keys¶

    Column Type Notes
    id VARCHAR(36) PK
    tenant_id VARCHAR(36) FK→tenants CASCADE delete
    name VARCHAR(255) Display name for the key
    key_prefix VARCHAR(20) First chars of the raw key (for identification)
    key_hash VARCHAR(64) UNIQUE SHA-256 hex digest of the raw key
    scopes JSON List of strings: analysis, interop, patients, cases
    created_by_id VARCHAR(36) FK→users NULL
    created_at DATETIME
    last_used_at DATETIME NULL Updated on each authenticated request
    expires_at DATETIME NULL NULL = never expires
    is_active BOOLEAN
    revoked_at DATETIME NULL Set on soft-revocation

    Indexes: (key_hash), (tenant_id).

    Enum persistence note¶

    All ENUM values are stored as their Python .value strings — German domain vocabulary is intentional and stable (e.g. "akzeptiert", "offen"). These values are part of the API contract and are never renamed without a migration. The frontend translates them for display via the i18n layer.
